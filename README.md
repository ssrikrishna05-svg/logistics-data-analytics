# Logistics Data Analytics Internship Projects

This repository contains weekly Data Analytics internship projects focused on logistics and supply chain operations using Python.

## Weekly Projects

### Week 1 – Strategic Planning and Data Exploration

- Identifying logistics challenges
- Defining Key Performance Indicators (KPIs)
- Planning logistics data analysis
- Developing a strategic roadmap

[View Week 1 Project](Week-1/)

### Week 2 – Data Collection, Cleaning, and Preprocessing

- Data collection and quality assessment
- Handling missing values and duplicates
- Outlier detection
- Data normalization
- Python-based preprocessing and visualization

[View Week 2 Project](Week-2/)

### Week 3 – Advanced Data Analysis and Visualization in Logistics

Project Focus: Performing advanced logistics data analysis using Python to identify operational patterns, evaluate delivery performance, and support data-driven decision-making.

Key Activities:

- Exploratory Data Analysis (EDA)
- Logistics KPI calculations
- Delivery performance and freight cost analysis
- Data visualization using Matplotlib
- Delivery time prediction using regression
- K-Means clustering analysis
- Model evaluation and business insights
- Critical reflection and recommendations

[View Week 3 Project](Week-3/)

### Week 4 – Predictive Modeling and Optimization in Logistics Systems

**Project Focus:** Developing predictive models to forecast logistics delivery times and applying optimization techniques to improve operational efficiency.

**Key Activities:**
- Predictive modeling using Python
- Data preparation and feature engineering
- Ridge Regression, Random Forest, and HistGradientBoosting
- Model training and chronological validation
- Performance evaluation using MAE, RMSE, and R²
- Hyperparameter tuning and model comparison
- Transportation cost optimization
- Resource allocation and delivery planning
- Business insights and actionable recommendations

**Project Results:**
- Simulated shipment records: 3,600
- Test MAE: 1.67 hours
- Test RMSE: 2.11 hours
- Test R²: 0.943
- Optimization demonstrated using simulated transportation scenarios.

**Note:** The results are based on simulated data and are intended for educational analysis.

[View Week 4 Project](Week-4/)
