Week 4 Internship Project: Predictive Modeling and Optimization in Logistics Systems Using Python

This Week 4 report presents a fully executed educational logistics forecasting and optimization workflow. The chosen prediction problem is to estimate shipment delivery duration in hours from information hypothetically known when a shipment is planned, including route distance, shipment weight, region, expected weather and traffic conditions, service priority, and transport mode. I created and documented a reproducible synthetic dataset of 3,600 shipment records. The exercise uses simulated observations because the task permits a hypothetical dataset; the report does not claim that these records represent real shipments. The Olist Brazilian E-Commerce Public Dataset is cited only as background research for possible future external validation.

Data were separated chronologically by booking date into 2,499 training records, 566 validation records, and 535 held-out test records. Python pipelines and expanding-window cross-validation were used to compare Ridge Regression, Random Forest, and HistGradientBoosting, alongside a median baseline. Hyperparameters were selected through training folds, and the final model was chosen using independent validation error. The best selected HistGradientBoosting model achieved a test MAE of 1.668 hours, RMSE of 2.107 hours, and R-squared of 0.943; the corresponding median baseline MAE was 7.158 hours. I included residual analysis by shipment segment, permutation importance, a prediction-error calibration check, and nine visualization figures.

For logistics optimization, I developed a mixed-integer programming demonstration that allocates 60 sample shipment profiles across road, rail, and air modes while obeying illustrative rail and air capacity constraints and a 15-percent tariff budget allowance compared with an all-road benchmark. Under the model assumptions, total predicted late hours declined from 206.78 to 3.62 while hypothetical tariffs increased by 14.63 percent. I also performed budget and service-time stress testing to show how sensitive the allocation recommendation is to budget and prediction uncertainty. These are forecast-based counterfactual comparisons rather than achieved commercial results.

The Word report explains data assumptions, modeling choices, code execution, MAE/RMSE/R-squared, cross-validation, optimization equations, actionable business recommendations, risks, limitations, and a proposed pilot implementation. The GitHub project contains runnable scripts, generated input data, model outputs, charts, a complete README, a data dictionary, and a verification utility.
